This repository holds the program that ships my GTA 6 clip for the make.fun bounty gta6-clipper-01. The clip is an 11-second vertical Short cut from Rockstar's official GTA VI Launch Trailer.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Requires Node.js 22.18 or newer. The program reads VIDEO.json from the repository root and copies it to the output directory. The video itself is uploaded to YouTube by the account owner; this program only carries its link (VIDEO.json) to the scorer.
